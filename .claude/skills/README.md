# Skills del proyecto

Estas skills se cargan automáticamente en las sesiones de Claude Code que
trabajen en este repositorio. Cada carpeta contiene un `SKILL.md`.

## Instaladas

**Diseño / frontend**
- `design-taste-frontend` — anti-cliché de IA para interfaces (un acento, asimetría, copy con números).
- `minimalist-ui-premium` — UI editorial, paleta cálida, sin sombras pesadas.
- `brand-guidelines` — aplica colores y tipografía de marca de forma consistente.
- `excalidraw-diagram` — genera diagramas `.excalidraw` que argumentan.

**Automatización n8n** (requieren tener las herramientas MCP de n8n disponibles para ser funcionales)
- `n8n-code-javascript`, `n8n-code-python` — Code nodes.
- `n8n-node-configuration`, `n8n-validation-expert`, `n8n-mcp-tools-expert`, `n8n-workflow-patterns`.

## No instaladas aquí (son plugins, no skills de carpeta)

`gws-cli`, `skill-creator` y `playwright` venían como `INSTRUCCIONES.md` de plugins.
Esos se instalan desde Claude Code con el comando `/plugin`, no copiando un `SKILL.md`.
